# test/

Nơi để ghi kết quả test thủ công (không phải unit test tự động ở giai
đoạn này) cho từng phase, ví dụ:

- `phase1_audioplaybackcapture.md` — kết quả test capture nhạc từ
  YouTube trên Phone 1: có lấy được PCM không, sample rate/format ra
  sao, có bị silence không.
- `phase2_latency_mic_to_speaker.md` — số đo latency thực tế.
